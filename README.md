
# CareerOS AI 🚀
### Your Personal AI-Powered Academic & Career Companion

CareerOS AI is an intelligent personal platform designed to help students manage their academics, improve technical skills, prepare for placements, and build a successful career — all from one place.

## ✨ Core Modules

- **Dashboard** — Your academic and career progress at a glance.
- **Personal AI Assistant** — Study Tutor, Career Mentor, Coding Buddy, Exam Coach and more.
- **Academics** — Manage subjects, assignments, exams and learning resources.
- **Career Intelligence** — Build a personalized career roadmap and identify skill gaps.
- **Company Preparation** — Prepare for company-specific recruitment processes.
- **Learning Roadmap** — Follow structured learning paths.
- **Coding & DSA** — Track coding practice and problem-solving progress.
- **Habit Tracker** — Build consistent study and productivity habits.
- **Daily Mission Control** — Organize daily goals and tasks.
- **Calendar** — Manage your schedule and important events.
- **Resume Builder** — Improve your resume and professional profile.
- **Internship Tracker** — Organize internship opportunities and applications.
- **Analytics** — Track academic, career and productivity performance.
- **Memory Center** — Manage personal learning context and AI memory.
- **Settings & Privacy** — Control preferences, permissions and privacy.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Next.js | Frontend framework |
| TypeScript | Type-safe development |
| Tailwind CSS | UI styling |
| Supabase | Database and authentication |
| Vercel | Deployment |

## 🔐 Security & Privacy

- User authentication through Supabase.
- Row Level Security (RLS) for user data.
- Environment variables for configuration.
- User-controlled AI permissions and privacy settings.

## ⚙️ Project Setup

Clone the repository:

```bash
git clone https://github.com/avinashvishwakarma62/-CareerOS-AI.git
```

Navigate to the project:

```bash
cd -CareerOS-AI
```

Install dependencies:

```bash
npm install
```

Configure environment variables in `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Run the application:

```bash
npm run dev
```
